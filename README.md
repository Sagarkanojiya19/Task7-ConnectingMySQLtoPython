# 📊 Sales Data Analysis with MySQL and Python

This project analyzes sales data from a **MySQL database** using **Python (pandas + matplotlib)**. It focuses on **product performance, monthly sales trends, and category-wise revenue**.

---

## ✅ Features

- Connects to a MySQL database using `mysql.connector`  
- Executes SQL queries to extract:
  - Total quantity and revenue by product  
  - Monthly order volume  
  - Revenue and order volume by product category  
- Visualizes revenue by product category with a bar chart  

---
